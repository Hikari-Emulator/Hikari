# Third-Party Dependencies

All third-party dependencies must be pinned by commit hash in `third_party/` or via CMake `FetchContent` with a hash check (`AGENTS.md` §1).

> **Dynarmic provenance note:** `third_party/dynarmic` is a git submodule pointing to `git@github.com:Hikari-Emulator/dynarmic.git` (`hikari/clang22-build` at `5373c127ff58449b1488a649c21686b597312917`), branched from `base/9d45823` (`9d4582339990d4eae53f1dc7160686920fc2075c`, `2024-03-05`) of `https://github.com/yuzu-mirror/dynarmic.git`, which is an unofficial mirror (its own repository description states so). The upstream author's repository (`merryhime/dynarmic`) was no longer available at the time of this pin, so base provenance is recorded as **"mirror; upstream not verified."**
>
> **Excluded from `third_party/dynarmic/` build:** `DYNARMIC_TESTS=OFF` excludes `tests/` and `externals/catch/` (`Catch2`, Boost Software License - Version 1.0 - August 17th, 2003 in `externals/catch/LICENSE.txt`).

## Dynarmic Build Integration Notes

- **Tested toolchain:** `clang version 22.1.8` (`x86_64-pc-linux-gnu`); Clang 18 is not tested.
- **Build & test command:** `cmake --preset debug && cmake --build --preset debug && ctest --preset debug`
- **Scoped options (`third_party/CMakeLists.txt`):** `DYNARMIC_TESTS=OFF`, `DYNARMIC_USE_BUNDLED_EXTERNALS=ON`, `DYNARMIC_FRONTENDS="A64"`, `DYNARMIC_WARNINGS_AS_ERRORS=OFF`, `add_subdirectory(dynarmic)`. No `-w`, `-Wno-error`, `FMT_CONSTEVAL=`, or `CMAKE_POLICY_VERSION_MINIMUM` is set.
